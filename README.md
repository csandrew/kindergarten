# Dukes Yatani Kindergarten Website

A modern, multi-page kindergarten website built with Next.js 14, TypeScript, and Tailwind CSS.

## Features

- Multi-page architecture (Home, About, Programs, Admissions, Contact)
- Fully responsive design
- Tailwind CSS with custom theming
- SEO optimized with page-specific metadata
- Lazy loading and code splitting for performance
- Accessibility-first design
- Google Analytics integration
- WhatsApp chat integration
- Online admissions form with validation
- Testimonial carousel with auto-play

## Tech Stack

- **Framework:** Next.js 14 (App Router)
- **Language:** TypeScript
- **Styling:** Tailwind CSS
- **Animations:** Framer Motion
- **Icons:** Lucide React, React Icons
- **Fonts:** Google Fonts (Inter, Poppins, Marcellus)
- **Analytics:** Google Analytics

## Getting Started

### Prerequisites

- Node.js 18+
- npm or yarn

### Installation

```bash
# Clone the repository
git clone https://github.com/your-username/dukes-yatani-kindergarten.git

# Navigate to project
cd dukes-yatani-kindergarten

# Install dependencies
npm install

# Start development server
npm run dev
